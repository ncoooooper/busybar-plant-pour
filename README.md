# Plant Pour

Log measured watering by plant and see what remains of each weekly volume target.

Set your own weekly targets as Plant|mL, separated by commas. Wheel chooses a plant. Click switches the wheel to volume in 10 mL increments, click again to finish editing. Start logs that pour. Hold the wheel undoes the last pour from the current week. Totals use local weeks beginning Monday.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
